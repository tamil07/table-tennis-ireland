## Why

The Leeside public website needs four things the current site lacks: the club's own logo as the browser icon, a way to show closures and holidays on the home page and timetable, a way to tell subscribers about closures, and a map of the address that visitors can open.

## What Changes

- Use the club's logo as the browser tab icon and home-screen icon, in the standard sizes.
- Let club admins record closures and public holidays. Closures show on the home page, timetable and structured data, and can be sent to opted-in subscribers.
- Add a newsletter opt-in with explicit consent, a double opt-in confirmation, and a one-click unsubscribe in every message.
- Show the club address with an "Open in Google Maps" link. Offer an embedded map that loads only after the visitor clicks.

## Impact

- Website: icons, home page closure banner, timetable closure markers, address and map block, consent checkbox.
- Backend: closure publication in the public feed, subscriber list with consent evidence, closure notice through the existing notification outbox.
- Operations: owner supplies the original logo file and confirms holiday dates each year.
- Privacy: privacy notice updated for the map and newsletter.
